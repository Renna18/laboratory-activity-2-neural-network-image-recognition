
# Can a Simple Neural Network Recognize Images?

This repository contains the implementation of Laboratory Activity 2 for the Computer Vision course. The project explores how a simple neural network can learn patterns from image data and use them to recognize or classify images.

## Methodology

The activity involves preparing image data, configuring a neural network, training the model, and evaluating its ability to recognize images. The specific architecture, dataset, and evaluation process depend on the implementation.
